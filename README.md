# CFD Projects

CFD projects from my MSc in Computational Fluid Dynamics (Universitat Politècnica de València, 2025/26).
Each folder contains a README with the set-up, key results and figures, plus the original report or presentation.

**Author:** Nieves Castellanos Arnáez · [LinkedIn](https://linkedin.com/in/nievesca29)

## Projects

| # | Project | Focus | Tools |
|---|---|---|---|
| 01 | [Centrifugal compressor (MRF to RBM)](01-centrifugal-compressor-mrf-rbm) | Turbomachinery, convergence strategy, energy balance | STAR-CCM+ |
| 02 | [Turboprop: geometry and meshing](02-turboprop-geometry-meshing) | Parametric CAD, hybrid meshing, MRF vs RBM set-up | STAR-CCM+ |
| 03 | [Hydraulic jump over an ogee weir](03-ogee-weir-hydraulic-jump-openfoam) | Free-surface two-phase flow, y+ analysis | OpenFOAM |

| 05 | [Diesel spray (ECN Spray A)](05-diesel-spray-euler-lagrange) | Euler-Lagrange sprays, atomisation and evaporation | STAR-CCM+ |
| 06 | [Cavitation in a throttle nozzle](06-nozzle-cavitation-schnerr-sauer) | Schnerr-Sauer cavitation model, parameter tuning | STAR-CCM+ |
| 07 | [VOF tank filling with AMR](07-vof-tank-filling-amr) | Interface capturing, mesh and time-step sensitivity | STAR-CCM+ |

## Notes

- Projects 02 and 04 to 08 were developed in teams. Collaborators are named in each project README.
- Geometry files provided by the course (compressor and turboprop CAD) are **not** included.
- Project 03 includes a baseline OpenFOAM case. See its README for how it differs from the final case used in the report.
